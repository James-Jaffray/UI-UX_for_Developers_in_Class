A Flex Container

In order to use Flexbox, you need an element that will be the flex container. In your CSS, you use display: flex:

This defines a flex container and it enables a flex context for all its direct children

Flex Items

Flex items are the direct elements within a flex container that are laid out using flexible box (flexbox) layout. Flexbox is a CSS layout module that provides an efficient way to arrange, align, and distribute space among elements in a container.
